# Ventures Harbor

## Backend setup

1. Start XAMPP Apache + MySQL.
2. Open http://localhost/venture/setup.php to create the MySQL database and tables.
3. Then open http://localhost/venture/users/auth.php and sign in or create an account.

## Structure

- config/: database and SQL setup
- api/: PHP endpoints for auth and profile
- users/: auth and profile pages
- assets/js/: frontend logic connected to the backend
